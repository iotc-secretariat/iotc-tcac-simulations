# Reference Data Panel

1. Reference data top panel

Explore NJAs in the Indian Ocean. Zoom, pan, and toggle layers for boundaries, coastlines, and overlapping claims.

2. Reference data bottom panel – Chart

View catch by entity, species, and spatial origin. Hover for values, toggle categories in the legend, and use top-right controls to zoom or download.

3. Reference data bottom panel – Data

Interactive table of catch estimates by entity, fishery, species, and spatial origin. Filter and search as needed.

4. Simulation configuration parameter panel – General

Select species, set the TAC, and assign allocation weights to distribute the TAC among IOTC entities.

5. Simulation configuration parameter panel – Developing States Weight Components

Set the relative weight of Equal, LDC, and SIDS sub-components for coastal developing States.

6. Simulation configuration parameter panel – Catch-Based Weight

Choose the reference period and method for historical catches, and define the 10-year sequence to reallocate foreign-caught TAC to coastal States.
